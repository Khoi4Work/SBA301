# SBA301
RAG about philosophy

## Prerequisites

Before running this project, you need to install and configure the following tools:

### 1. Ollama
Ollama is used to run large language models and embedding models locally.

- **Download and Install:** Visit [ollama.com/download](https://ollama.com/download) and follow the instructions for your operating system.
- **Pull Embedding Model:** Once Ollama is installed and running, open your terminal/command prompt and run the following command to download the `nomic-embed-text` model:
  ```bash
  ollama pull nomic-embed-text
  ```

### 2. edge-tts
`edge-tts` is used for text-to-speech conversion.

- **Install via pip:** Ensure you have Python installed, then run:
  ```bash
  pip install edge-tts
  ```
